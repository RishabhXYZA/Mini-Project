# 🌦️ Weather App (Tkinter + OpenWeatherMap API)
A simple desktop weather application built with Python (Tkinter) that shows the current weather, daily minimum & maximum temperature (calculated from forecast data), humidity, pressure, wind speed, and
sunrise/sunset times — with emoji-based UI for a better user experience.

# ✨ Features

1. ✅ Fetches real-time weather data using OpenWeatherMap API
2. ✅ Calculates daily Min/Max temperature from 3-hour forecast data (works on free API plan)
3. ✅ Displays:
      - 🌡️ Current Temperature;
      - 🔺 Max Temperature & 🔻 Min Temperature;
      - 🧭 Pressure;
      - 💧 Humidity;
      - 🌬️ Wind Speed;
      - 🌅 Sunrise & 🌇 Sunset;
4. ✅ Emoji-based UI for a modern and fun look
5. ✅ Simple & lightweight Tkinter GUI

# Installation
1. Clone this repository:
 git clone [Repositry Link]

2. Install required packages:
      pip install requests

3. Run the app:
      weather_app.py

# 🔑 API Setup

1. Get a free API key from OpenWeatherMap
2. Replace YOUR_API_KEY in weather_app.py with your actual key:
3. appid=YOUR_API_KEY

# 📌 Usage
1. Enter the city name in the text field.
2. Press Enter or Return key.
3. See current weather, min/max temperatures, and other details instantly!
